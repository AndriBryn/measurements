Set up 

The set up for the test consists of two lines spaced 20 meters (run zone) and a recovery zone spaced 5 meters from the run zone 

Start line = line A 

End line = line B 

Recovery line = C line 

 

Instruction 

Beginning of the test:  

All athletes line up along the starting line. The athletes start with a foot behind line A, and begin running when instructed by the audio recording towards line B. The Athlete recovers inside the rest zone in-between shuttles. 

During the test: 

The athletes shuttle back and forth between the two lines in time to the audio cues. The athlete must not start running early, must run the complete distance, and reach each line before or in time with the audio cues. At regular intervals, the time between audio signals will reduce, and consequently the required running speed will increase.  

Towards the end of the test: 

The athletes must continue for as long as they can. Some of the athletes will choose to stop when they have reached their physical limit. For others, you will need to give a warning as they drop behind the required pace. Each player is allowed one warning.
